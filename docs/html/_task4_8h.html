int calculateHeight ( TreeNode * root)

Calculates the height of a given binary tree.

The height is the longest path from the top of the tree (the root) to a node at the bottom (a leaf). A tree with only one node has a height of 0. An empty tree is considered to have a height of -1.

Parameters
rootA pointer to the root node of the tree.
Returns
The height of the tree as an integer.

Calculates the height of a given binary tree.

This function works by recursively finding the height of the left and right branches from the current node. It then takes the larger of those two heights and adds one to it to account for the current level. This process repeats until the bottom of the tree is reached.

Parameters
rootA pointer to the root node of the tree.
Returns
The integer height of the tree. It returns -1 if the tree is empty.
