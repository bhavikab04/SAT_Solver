Detailed Description

Header for functions that evaluate logical formulas.

This file outlines the tools for processing logical expression trees. It includes functions for finding a formula's result, using variables from a file, and creating a full truth table.

◆ MAX_TRUTH_TABLE_VARIABLES

#define MAX_TRUTH_TABLE_VARIABLES   25

A safety limit to avoid creating excessively large truth tables.

The number of rows in a truth table grows exponentially (2^n). This limit prevents the program from becoming unresponsive with too many variables.

Evaluates a formula using variable values from a file.

This function reads a file where each line assigns a value to a variable (e.g., "p = T"). It uses these assignments to evaluate the formula tree.

Parameters

Returns
Returns true if evaluation was successful, false if the file could not be read.
