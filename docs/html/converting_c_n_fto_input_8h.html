Converts a CNF file into a single-line, fully parenthesized infix expression and writes it to the provided stream.

This function implements a streaming algorithm to avoid building the entire (potentially massive) infix string in memory.

It builds an expression of the form: (C1 * (C2 * (C3 * C4)))

Parameters
filenameThe path to the DIMACS CNF file.
