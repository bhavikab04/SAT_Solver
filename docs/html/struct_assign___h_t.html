Detailed Description

The internal structure of the hash table.

A structure for efficiently storing variable assignments.

An array of pointers, where each pointer is the head of a linked list.

This is an "opaque" type, meaning its internal details are managed in the .c file. Code outside that file interacts with it through a pointer.
