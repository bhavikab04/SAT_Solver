Checks if a CNF formula is a tautology.

A CNF formula is a series of 'OR' clauses joined by 'AND'. The entire formula is a tautology only if every individual 'OR' clause is also a tautology. A clause is a tautology if it contains a variable and its negation, like (p OR ~p). This function counts the valid and invalid clauses.

Parameters
cnf_rootThe root node of the CNF formula tree.
[out]valid_clausesA pointer to an integer that will hold the count of valid clauses.
[out]invalid_clausesA pointer to an integer that will hold the count of invalid clauses.
Returns
Returns true if the formula is a tautology (zero invalid clauses), and false otherwise.
