◆ task1_infixToPrefix()

Stack * task1_infixToPrefix ( const char * infix)

Converts an infix expression string to a prefix expression stack.

  • This function implements the Shunting-yard algorithm modified for infix-to-prefix, which involves scanning the infix string from RIGHT to LEFT.
Parameters
infixThe null-terminated infix expression string.
Returns
A pointer to a Stack containing the prefix expression tokens. The tokens are ordered such that popping from the stack gives the reverse prefix order, but iterating the stack->data array from top-to-bottom gives the correct prefix order. Returns NULL on failure or empty input.
