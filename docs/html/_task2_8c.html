◆ prefixToTree()

TreeNode * prefixToTree ( Stack * prefix_stack)

Iteratively builds a parse tree from a prefix expression stack.

Converts a prefix expression, stored in a stack of string tokens, into a parse tree. The stack is consumed during this process.

This algorithm works by processing tokens one by one from the prefix stack (which was generated by task1_infixToPrefix). It uses a second stack (NodeStack) to keep track of parent nodes (operators) that are waiting to be assigned children.

Parameters
prefix_stackThe stack of prefix tokens (from Task1).
Returns
A pointer to the root TreeNode of the constructed parse tree.
