Evaluates the truth value of a parse tree given truth values for its atoms.

This function traverses the tree in a bottom-up (post-order) fashion. It recursively evaluates the children of a node before applying the operator at the node itself.

Parameters
rootA pointer to the root node of the parse tree.
assignmentsAn array of TruthAssignment structs that provide the boolean values for each atom in the formula.

The final boolean truth value of the entire formula.
